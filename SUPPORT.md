# Support

This plugin is maintained on a best-effort basis as a personal open-source project — there is no SLA and no commercial support.

## How to get help

| Need | Where to go |
|---|---|
| Plugin bug | [Open a bug issue](https://github.com/l-teles/tailpipe-plugin-crowdstrike/issues/new?template=bug.yml) |
| Feature request | [Open a feature issue](https://github.com/l-teles/tailpipe-plugin-crowdstrike/issues/new?template=feature.yml) |
| Security vulnerability | [Private vulnerability report](https://github.com/l-teles/tailpipe-plugin-crowdstrike/security/advisories/new) — see [SECURITY.md](SECURITY.md) |
| Tailpipe CLI itself | [turbot/tailpipe](https://github.com/turbot/tailpipe/issues) |
| CrowdStrike FDR product / data | [CrowdStrike Support Portal](https://supportportal.crowdstrike.com/) |
| Usage questions ("how do I query…") | Open a feature issue describing what you want to ask — repeated questions get distilled into the per-table `docs/tables/<table>/queries.md` files. |

## Response expectations

| Severity | Target first response |
|---|---|
| Critical security finding | 72 hours |
| Bug, plugin won't work for documented use case | 1 week |
| Feature request, polish, docs | best-effort |
